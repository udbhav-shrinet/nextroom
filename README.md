# NEXTROOM // Spatial Room OS & Sanctuary Audio Station

> **A 24/7 living sanctuary combining keyboard-first tactile hardware, living layered room scenery, global radio frequencies, studio DSP audio engineering, and a focus wellness toolkit.**

Live Deployment: [https://udbhav-shrinet.github.io/nextroom/](https://udbhav-shrinet.github.io/nextroom/)

---

## 🌟 Architecture & Core Pillars

### 1. 95% Viewport Living Room OS
- **Living Architectural Art Canvas:** Multi-layer parallax living room with high-rise skyline silhouettes, alpine pines, and animated window blinds.
- **Physical Room Lighting Controls:**
  - **Desk Lamp Dimmer & Kelvin Warmth:** 0–100% brightness, 2400K (candle) to 6500K (daylight) physical color temperature simulation, and draggable light pool.
  - **Midnight Dimmer:** 0–90% ambient darkness ramp.
  - **Window Rain Refraction:** Dynamic HTML5 canvas simulating rainfall density, streaking droplet physics, and glass condensation.
  - **Fireplace Hearth:** Warm, flicking hearth embers with bass-linked glow.
  - **Neon Wall Sign:** Customizable text, color picker, and bass-reactive halo.
  - **CRT & Film FX:** Scanline intensity, phosphor bloom, and retro display simulation.
  - **Interactive Tactile Props:** Clickable desk lamp, purring companion cat, steaming warm coffee cup, window blind cords, and draggable sticky notes pinned directly to the room wall.

### 2. Global Radio & Universal Audio Engine
- **Direct Radio-Browser API Integration:** Access to 40,000+ live terrestrial and internet radio stations worldwide with mirror failover and country/tag search.
- **30 Flagship Presets:** Instant, curated streams (SomaFM Groove Salad & Drone Zone, Nightride FM, Chillsynth FM, Datawave FM, Radio Paradise channels, TSF Jazz Paris, KEXP Seattle, FIP Radio France, DEF CON Radio, Ambient Sleeping Pill, Dublab LA, NTS London, etc.).
- **🎲 World Spin:** One-click random station discovery across any country on Earth.
- **BYOA (Bring Your Own Audio):** Local drag-and-drop audio player (.mp3, .flac, .wav, .ogg, .aac).
- **Custom Stream URL:** Direct Icecast, Shoutcast, and HLS URL streaming.
- **Offline Procedural Lo-Fi Synth:** Automatic fallback Rhodes chord & sub-bass generator so the sanctuary is never silent.
- **WebSocket Bridge:** Two-way bridge to `ws://localhost:7474` for CLI-driven control.

### 3. Studio Rack Equalizer & Master DSP
- **10-Band Graphic/Parametric EQ:** 31Hz, 63Hz, 125Hz, 250Hz, 500Hz, 1kHz, 2kHz, 4kHz, 8kHz, 16kHz (±12dB).
- **Live 128-Bin FFT Spectrum Visualizer:** 60fps real-time frequency analysis canvas.
- **🚪 Next Room / Door Muffle Switch:** Hardware 380Hz 24dB/oct cascaded low-pass filter with room reverb send, simulating stepping outside the room into the hallway.
- **Soft-Clipper Tube Saturation:** Adjustable warmth, tape compression, and subtle harmonic distortion.
- **Algorithmic Space Reverb:** Convolver impulse response with wet/dry mix.
- **8D Auto-Orbit Panner:** Circular stereo LFO panning across headphones.
- **📼 Varispeed Pitch & Speed:** 0.5× to 1.5× playback rate (Slowed + Reverb vs. Nightcore Speed).
- **15 Built-in EQ Presets:** Flat, Deep Sub Bass, Bass Boost, Treble Boost, Lo-Fi Telephone, Warm Vinyl 70s, Late Night Study, Vocal Presence, AM Car Radio, Cassette Deck, Cathedral Air, etc.

### 4. 36-Stem Environment, Weather & Voices Mixer
- **Independent Stems:** Volume slider, L/R Stereo Pan, and tone filtering for each stem.
- **Weather & Elements:** Window Drizzle, Tin Roof Rain, Distant Thunder, Blizzard Wind, Ocean Waves, Forest Creek.
- **Fire & Earth:** Hearth Wood Fire, Simmering Tea Kettle, Dripping Cave Cavern.
- **Cozy Interiors:** Parisian Cafe Murmur, Overnight Sleeper Train, Grandfather Clock Tick, Vinyl Dust & Needle Pops, Cassette Tape Hum.
- **City & Machines:** Deep Subway Rumble, Desk Fan Hum, Data Center Rack Whir, Starship Warp Core Drone.
- **Voices, Comms & Chatter:** Live Tower ATC Comms, NASA Apollo Telemetry, Cyberpunk Dispatch Scanner, Tokyo Izakaya Murmur, Spoken Contemplation, AI Sanctuary DJ.
- **ASMR & Brainwaves:** Thocky Keyboard, Sleeping Cat Purr, Linen Page Turning, 10Hz Alpha Focus, 40Hz Gamma Flow, 4Hz Theta Zen, 432Hz Solfeggio Harmonic, Singing Bowl, Brown Noise, Pink Noise, White Noise, Felt Lo-Fi Piano.
- **🎲 Serendipity Mix:** Random curated mix recipes (Rainy Cafe, Cabin Blizzard, Space Observation, Tokyo Night).
- **Silence All:** Instant one-tap ambient panic mute.

### 5. 24 Curated Themes & Scenery Engine
- **Terminal & Aesthetics:** Sila Purple, Tokyo Night, Catppuccin Mocha, Gruvbox Amber, Nord Aurora, Dracula, Rosé Pine, Kanagawa Wave, Solarized Dark.
- **Tactile Hardware:** TE OP-Field, Pip-Boy Green, Amber CRT 1984, Cyberpunk Yellow, Walkman Silver, Braun Rams.
- **Cozy Atmospheric:** Kyoto Matcha, Midnight Espresso, Rainy Violet Neon, Fireplace Terracotta, Deep Ocean Biolume, Sakura Twilight.
- **Daylight & Paper:** E-Ink Daylight, Muji Linen, Architect Blueprint.
- **Living Room Scenery:** Tokyo Midnight Desk, Cyberpunk Rooftop, Paris Rain Cafe, Nordic A-Frame Hearth, Kyoto Bamboo Mist, Swiss Alps Sleeper Carriage, Orbital Cupola, Deep Sea Bioluminescence, Synthwave Grid, Ancient Treehouse Study, Midnight Library Storm, Kerala Houseboat Monsoon.

### 6. Focus & Wellness Productivity Suite
- **Pomodoro Timer:** 25m / 50m / 90m modes, completed session counter (🍅), focus minutes tally, auto-muffle on breaks, singing bowl chime.
- **To-Do Queue:** Priority tags (P1–P3), estimated pomodoros, task check-off chimes, and `[ 🎯 Lock In ]` feature pinning the active task to the top HUD.
- **Markdown Notes & Wall Sticky Notes:** Live word/char counters, clean editor, and one-click `[ 📌 Pin to Room Wall ]` sticky notes with random pastel tints and rotation.
- **Breathing Pacer:** Box breathing (4-4-4-4) visualizer with animated halo orb and cycle phases.
- **Water Hydration Tracker:** 2500ml daily target, animated liquid bottle fill, quick-add buttons (+250ml glass, +500ml bottle).
- **Open-Meteo Weather Widget:** Keyless real-time temperature, condition, humidity, wind speed, and precipitation.
- **World Clock & Meeting Planner:** Real-time clocks across Tokyo, Paris, London, New York, San Francisco, Zurich.

### 7. 8-Pad Lo-Fi Sampler & 16-Step Sequencer
- **Hardware MPC Style Pads:** Keys 1–8 or click triggers (Warm Rhodes, Lo-Fi Kick, Crisp Snare, Hi-Hat Sizzle, Vinyl Rewind, Thunder Clap, Singing Bowl, Water Plink).
- **16-Step Sequencer:** Multi-track pattern matrix with real-time BPM adjustment and loop playback.

### 8. Station-Synced Lounge & Presence
- **BroadcastChannel Relay:** Multi-tab synchronized room chat without requiring external servers.
- **Share My Vibe Cards:** 1-click share of your current station, theme, and scenery with instant `[ 🎧 Apply This Vibe ]`.
- **Floating Reactions:** ✨ ☕ 🔥 🌧️ 💜 🧠 🌙 🎧.

### 9. Command Palette (`:` or Ctrl/Cmd + K)
- Full keyboard-first fuzzy command bar:
  - `:muffle` - Toggle Next Room door muffle DSP
  - `:spin` - World spin random active station
  - `:theme <name>` - Instant theme switch
  - `:scene <name>` - Instant scene switch
  - `:vol <0-100>` - Set master volume
  - `:zen` - Toggle Zen mode

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/udbhav-shrinet/nextroom.git
cd nextroom

# Install dependencies
npm install

# Run locally in development mode
npm run dev

# Build for production
npm run build
```
